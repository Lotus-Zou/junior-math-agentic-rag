# 数学 Agent 升级记录

本文件记录通用 RAG 到初中数学错题系统的已完成升级，不再作为待办计划。

## 已完成

- 用 LangGraph 显式状态图实现 Workflow + Agent 混合编排，区分确定性错题订正链与有界 ReAct 知识问答分支。
- 增加结构化错题解析、查询改写与多 Query 分解，保留公式、题设和多轮指代。
- 检索升级为章节分类召回、稠密向量 + BM25 双检索、轻量 GraphRAG 前置知识扩展、RRF 融合与独立 LLM-Rerank。
- 入库实现公式保护与 280/380/700 token 自适应分块，并为每个 Chunk 补充年级、章节、知识点、题型、错因、公式和前置依赖。
- 生成 Agent 只基于带来源片段输出引导式订正过程，不把无依据草稿作为最终答案。
- 独立 Critic 组合教材事实忠实度与 SymPy 确定性逻辑检查，失败可回流检索/推理，重试耗尽后拒绝输出。
- 加入 Pydantic Schema、工具白名单、最大步数、超时和业务护栏组成的运行时约束层。
- 建立工作记忆、会话记忆、长期薄弱点三级记忆，并在上下文溢出时摘要压缩。
- 将四个业务 Skill 同时接入 LangGraph Tool-Calling 与 MCP 2.1 stdio 服务。
- 建立 1000 条分层标注集，以及检索 A/B、RAGAS、业务指标、质量门禁和逐 case Trace。
- 提供 FastAPI、反馈池、Prometheus、Redis/本地缓存、Dockerfile 与 Docker Compose。
- 历史项目指标单独记录 provenance 与复现状态，避免把简历口径误报为当前回归结果。
- 当前本地索引验证为 1 份示例资料、12 个 Chunk、33 个 GraphRAG 节点；正式效果评测需补充完整教材语料。
